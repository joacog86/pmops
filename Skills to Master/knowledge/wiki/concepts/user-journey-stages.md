# User Journey Stages (PLG Flywheel)

**Type:** Concept / Framework

## The 5 stages

| Stage | User type | What they need | Failure mode |
|---|---|---|---|
| Evaluate | Stranger | Clarity: what it does, vs. competitors, cost | Confusing positioning or pricing |
| Activate | Explorer | Fast path to core value | Feature overload, slow onboarding |
| Adopt | Beginner | Habit formation, workflow integration | Drop-off after initial use |
| Expand | Regular | New use cases, proactive engagement | Ignored until renewal time |
| Advocate | Champion | Recognition, easy ways to share | Never asked, never act |

## Key insight: not all users go through all stages

From the PLG Flywheel source:
- Viral loop products (Drift) can skip Expand → go straight to Advocate
- Two-sided marketplaces (Wise) pull suppliers in who skip Evaluate entirely
- Multi-player products (Slack) create micro-flywheels per new invitee

## How to use this in practice

- Map your actual user cohorts against these stages — where do most people drop off?
- Each stage needs a different team owner and different success metric
- Don't treat all users the same — a Regular needs different engagement than a Beginner
